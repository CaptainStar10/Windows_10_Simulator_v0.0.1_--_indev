# Windows_10_Simulator_v0.0.2_--_indev
*Windows 10 like simulator in your browser(v0.0.2 indev)*

Finally, a new update for the *Windows 10-like* OS. The update v.0.0.2 indev(launched on 31/08/2026) recreate how the taskbar, the settings app interact with the OS and much more. With this update we are making every version of *Windows 10-like* OS in a folder with the name and its version.

1. Major updates:
    1. Time and date: Added time and date to the bottom right section of the taskbar. Right now, while testing, it shows the time and date from Romania, but it might work with other timezones.
    2. Calendar: Added a new **Calendar** application in the same spot as the *Time and date* features. Right now it will open only a flat plane where the notifications will go.
    3. Widgets: Added a new **Widget** application that *RIGHT NOW* acts like the Calendar app. In the future versions both will get separate functions.

2. Minor updates:
    1. Improvements to the taskbar and start menu.
    2. Improvements to the settings application.
    3. Introducing a new *Sound* engine that right now only plays a notification sound. It can be activated from settings.
    4. Project structure rework. Now there is a different project structure. Older versions will not be compatible with the new features.
