# Windows_10_Simulator_v0.0.1_--_indev
*Windows 10 like simulator in your browser*

A new way to interact with an operating system without using a VM.
This project was originally made in 1.5 days(excluding the sleep, pause, eating, etc.) under the name Windows10X as a Windows 10 with Windows 11 features.
The project is 2k lines of code for rendering icons, desktop, taskbar, the start menu and applications(700 lines of code were just for the applications) where right now the same code(without the icons, start menu being completed) the project has only around 1k lines which is about a **50% decrease** that does the same thing and it`s more readable.

**How it works?**
1. in the 'Windows 10 sim' folder there is an 'index.html' file which is the main file for the application.
2. once you open it you might notice that there is no taskbar. To activate the taskbar just move your mouse to the bottom of the screen and it`ll show up.
3. in the taskbar there are only 2 buttons:
   *. the start button
   *. a button that says 'A'
   The start button brings up the start menu. The second one opens settings which uses iframes to render the application. The settings application file is located int the 'html pages/Settings.html'.
